Home

This is a plain, static site served entirely by nginx — no application server, no compilation step. It exists to demonstrate nginx on its own before it gets paired with something else (like PHP) in a future hydras/* branch.

Everything here is production-grade: the official nginx image, a real server block in conf/default.conf, gzip enabled, and a /api/health endpoint per this repo's convention.
